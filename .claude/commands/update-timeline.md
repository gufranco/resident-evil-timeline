Add a new Resident Evil entry to the canonical timeline in README.md.

## Arguments

$ARGUMENTS

If no argument is provided, ask the user for the title of the new entry.

## Process

1. **Research the entry.** Search the web for the entry's full plot, in-universe dates, characters, biological threats, and lore significance. Use at least two sources (Resident Evil Wiki, Wikipedia, official Capcom site). Be thorough: read the full plot page, not just a summary.

2. **Read the current README.md** to understand the existing structure, format, and chronological ordering.

3. **Read .claude/CLAUDE.md** for the section format template and lore accuracy rules.

4. **Determine chronological placement.** Based on the in-universe dates, identify exactly where the new section belongs in the README. State the entry that comes before and after it.

5. **Write the new section** following the exact format of existing entries:
   - Title as H3 heading
   - Metadata block (dates, location, protagonists, antagonists)
   - Plot Summary (H4) with full chronological detail
   - Key Biological Threats (H4)
   - Lore Significance (H4)

6. **Update the Mermaid diagrams:**
   - Add the entry to the "Timeline Overview" Mermaid timeline diagram
   - If the entry takes place in 1998, also add it to the "Raccoon City Incident" gantt chart
   - If the entry introduces new biological agents, update the "Viral Genealogy" flowchart

7. **Update the reference tables:**
   - Add a row to the "Canon Status Reference" table
   - Add the entry's characters to the "Character Appearances" table
   - Update the "Key Organizations" section if new organizations are introduced

8. **Cross-reference connections.** Check if any existing entries reference or connect to the new entry. Add connection notes where relevant.

9. **Present the changes to the user** before writing. Show the new section and list all diagram/table updates.

## Quality Rules

- Every date must be verified against at least two sources
- Plot summaries must cover all major story beats, not just a high-level overview
- Follow the tone and density of existing sections: informational, no filler
- Do not modify existing sections unless adding a cross-reference connection
